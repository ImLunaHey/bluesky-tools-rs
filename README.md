# Bluesky Tools for Rust

An idiomatic, reusable Rust toolkit for building applications and bots on Bluesky and the AT Protocol.

## Crates

- `bluesky-bot`: high-level Bluesky bot client, resources, chat, events, caching, and rate limiting.
- `bluesky-jetstream`: typed, resilient consumer for AT Protocol Jetstream.
- `bluesky-richtext`: builder and data model for byte-accurate Bluesky rich text facets.

The workspace is under active development and has not yet been published to crates.io.
